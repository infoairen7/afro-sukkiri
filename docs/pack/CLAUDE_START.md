# Claudeに最初に渡す依頼文

以下をコピーして、同梱ファイルと一緒にClaudeへ渡してください。

---

添付した「アフロ、スッキリ。」の企画書とデザイン資料を読み、スマホとPCで動く3Dブラウザゲームを制作してください。

目的は、丸いアフロのおじさんの頭髪をバリカンで全部剃り、音・毛が落ちる様子・ツルツルの仕上がりを楽しむことです。全周を綺麗に剃れたらクリアタイムとスコアを表示し、Xに投稿文を送れるようにしてください。ゲームは日本語、スマホ縦画面優先です。

最初に docs/GAME_PLAN.md を読んでください。見た目はdesign内のPNG4枚（01・02・03・05）を目標にします。design/04_glb_preview.pngが同梱モデルの実際の簡易形状の参考です。精密な完成モデルや完成ゲームが入っているとは想定しないでください。

同梱GLBは、おじさん5点、髪型8点、バリカン6点（計19点）です。data/catalog.jsonにパスとパラメータ、data/hair_*.jsonに刈れる毛根データがあります。頭中心原点、+Yが上、+Zが顔正面で、髪型はおじさんと同じ座標に配置します。頭皮は半径[0.78,1,0.78]の楕円体です。眉と口ひげは残してください。

追加の人物仕様はdocs/CHARACTERS_V1_1.mdです。既存のbaseに、喜・にこ丸、怒・むす鉄、哀・しょん吉、楽・ゲラ蔵を加えた5人を、開始前に選べるようにしてください。data/characters.jsonを使用し、人物GLBと髪型は同じ原点で重ねます。キャラで能力・得点を変えず、結果カードとX文面に名前を追加。GLBは静止表情の簡易モデルで、表情モーフは未同梱です。

まずVite + TypeScript + Three.js等の適切な構成で、classicとstandardのみを使い、頭の前・後ろ・左右・上をちゃんと剃れる操作試作を完成させてください。画像を平面に貼っただけの疑似3Dや、頭全体の髪を一度に消す処理は不可です。

髪のGLBは静的な形状参照です。ゲーム中はJSONの毛根を元にInstancedMesh等で再構成し、currentHeightを個別に減らしてください。アフロが頭皮より外へ膨らむ部分もRaycasterで選べるようにしてください。髪／頭皮のヒット点を頭のローカル座標へ変換し、手前の範囲だけ削ります。高速な指移動で判定が抜けず、逆側の髪を貫通して剃らないようにしてください。最初は模型らしい簡易モデルで成立させ、その後にデザイン画へ質感・カール・表情を近づけてください。

スマホは1本指で剃り、正面／右／後ろ／左／上ボタンで視点を変えます。自由回転は別モードにし、同じドラッグで剃る操作と競合させないでください。髪型8種、バリカン6種の機能と数値は企画書・catalogを参照。全バリカンで完了できる仕様を守ってください。

スッキリ率は「完全に剃れた毛根の割合」。99％ではクリアにしません。全毛根の高さ0でタイムを固定します。得点計算は企画書第8章を厳守し、snippets/share-score.mjsの純粋関数を参照してください。フリーとタイムアタック（standard固定）は別記録です。中断したTAは自己ベスト対象外です。

Xボタンは、確定した結果のtext・hashtags・実際の公開URLをWeb Intentに渡し、本人の投稿画面を開きます。APIキーをゲームに埋め込まないでください。結果のPNG保存は別ボタンです。Web IntentでローカルPNGが自動添付される前提にしないでください。実際のX投稿そのものはユーザーに任せます。

進め方：A操作 → B完了と計測 → C共有 → D全バリエーション → E仕上げ。段階ごとに動く状態を保ってください。まずA～Cを一連で完成させてから、同じ実装を全髪型・道具へ展開してください。初版にログイン・広告・課金・オンラインランキング・育成を追加しないでください。

最終納品は、起動方法、ビルド方法、公開方法、全ソースと素材、依存関係の固定ファイル、確認済み機種／未確認点、残る制約を含めてください。企画書の受け入れチェックを実行し、実行できなかった項目はそのまま明示してください。

もし添付のバイナリGLBをClaudeの画面で直接読めなくても、存在しないと判断しないでください。利用する開発環境のpublic/assetsへ配置してください。配置できない環境ならsource/build_models.pyとsource/build_characters.pyをこの順で実行して再生成するか、JSONから同じ座標系の簡易形状を生成してください。音声ファイルは未同梱なのでWeb Audio合成音から始めてください。

---

## 添付方法

1. まずCLAUDE_START.md、GAME_PLAN.md、designの4枚（01・02・03・05）を渡す。
2. 開発環境にmodels・data・snippetsを配置する。ZIP取り込みが使える環境では制作パックを解凍して使う。
3. 同梱GLBは簡易形状なので、最初の操作版完成後にキャラと毛束の見た目を確認する。

このパックは完成ゲームではありません。3Dモデルの表情アニメーション、実際の剃毛処理、音、結果カード生成、レスポンシブUIはClaudeが実装する作業です。
