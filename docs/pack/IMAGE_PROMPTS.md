# デザイン画の生成プロンプト

組み込み画像生成で制作した目標ビジュアル。実際のGLBは別途制作した簡易立体モデルであり、画像と同等の毛束・表情・質感を持つ完成モデルではありません。

This is concept art for a shaving game, not gameplay, no blood or pain, no existing IP, no branding.
